# Capstone Machine Learning Project
Using Python and Jupyter Notebook, I worked with a public transportation trips dataset to explore how passengers use different transportation modes and identify meaningful patterns in the data.

My project involved:

Data cleaning and preparation.

Exploratory Data Analysis (EDA).

Descriptive statistics and data exploration.

Univariate, bivariate, and multivariable analysis.

Data visualization and correlation analysis.

Comparing transportation modes based on passenger volume, average fares, and trip duration.

The objective was to turn raw transportation data into meaningful insights that can support better decision-making and improve transportation services.

This project allowed me to apply my data analytics and Python skills to a real-world transportation challenge.
